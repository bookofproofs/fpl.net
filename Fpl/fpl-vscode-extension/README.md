# FPL (Formal Proving Language)

FPL, the Formal Proving Language, is a language to formulate mathematical definitions, theorems, and proofs independently of local natural languages.

This extension enables you to make use of advantages of an IDE like VS Code while writing code in FPL.

This is a Proof of Concept of a private research project to develop such a language. 

## Features

* A custom Formal Proving Language (FPL) for writing and structuring mathematical proofs independently of natural language, with rich mathematical notation and a continuously simplified, readable syntax
* A real interpreter with an execution engine capable of evaluating logical expressions and verifying proof correctness, not just parsing structure
* An extensive, fine-grained diagnostics system (100+ codes) for catching signature, syntax, and proof-justification errors
* A full-featured VS Code extension with syntax highlighting, autocompletion, symbol navigation, and a webview for browsing valid statements and rules of inference
* A Language Server Protocol implementation powering real-time diagnostics, completion, and document navigation
* Cross-platform support via on-demand .NET runtime acquisition for Windows, Linux, and macOS
* Automated versioning, changelog, and release-note synchronization across the solution and the VS Code extension's publishing pipeline
